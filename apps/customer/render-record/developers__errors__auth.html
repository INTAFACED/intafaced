Authentication and permission errors

For Exchange API

Every authentication and permission refusal a call to the trading REST API (/api/v1) can answer with. Branch on the code; the detail code names the decision behind it.

Authentication and permission errors

Code HTTP status Detail code Severity Category Cause What to do
AuthenticationError 401 auth.required Error: change the request Authentication No key was sent: the Authorization header is missing. Answered by the trading service, in its CCXT dialect. Send the key as Authorization: Bearer followed by the key.
edge.api_key_denied 401 auth.api_key_denied Error: change the request Authentication The key is wrong: no live key matches it, or a restriction on the key (origin, IP address, product or account) refused this call. Check the key string, then the key’s restrictions on the keys page.
edge.api_key_revoked 401 auth.api_key_revoked Error: change the request Authentication The key was revoked. Make a new key. A dead key cannot be brought back.
edge.api_key_expired 401 auth.api_key_expired Error: change the request Authentication The key has expired. Make a new key.
account_frozen 403 auth.account_frozen Error: change the request Account The account behind the key is frozen. Contact support about the account.
PermissionDenied 403 scope.denied Error: change the request Permission The key does not hold the scope this route needs. Make a key with the permission the route needs; the permission table lists them.
PermissionDenied 403 env.mismatch Error: change the request Permission A sandbox key called a live address, or a live key called a sandbox address. Call the address of the environment the key belongs to.
edge.request_unsigned 401 auth.request_unsigned Error: change the request Signature The key must sign every request, and this request carried no signature. Sign each request as the authentication page shows.
edge.request_stale 401 auth.request_stale Error: change the request Signature The request’s timestamp is older than the owner’s window. Check your clock against the server’s time, then sign again.
edge.request_future 401 auth.request_future Error: change the request Signature The request’s timestamp is ahead of the owner’s window. Check your clock against the server’s time, then sign again.
edge.request_tampered 401 auth.request_tampered Error: change the request Signature The signature does not match the request that arrived: the method, path, body or headers changed after signing. Sign exactly the method, path, timestamp, nonce and body you send.
edge.request_replay 401 auth.request_replay Error: change the request Signature The nonce was already used. Use a fresh nonce for every request.
edge.request_window_unset 503 auth.request_window_unset Temporary: the same request may succeed later Platform The owner’s signing window is not set, so no signed request is accepted. Nothing in the request can change this. Signed calls are refused until the owner sets the window.
edge.authority_unavailable 503 none Temporary: the same request may succeed later Platform The gateway could not ask the service that checks keys. Nothing ran. Retry after the Retry-After seconds.
