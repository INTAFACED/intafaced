# Permissions

Which permission a key needs for each route. On /api/v1 a key needs trade:read to read and trade:write for anything else; a key without it is refused with scope.denied and a link to this page.

| Permission       | Endpoints                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `trade:read`     | `GET /api/v1/time`, `GET /api/v1/capabilities`, `GET /api/v1/markets`, `GET /api/v1/ticker/:symbol`, `GET /api/v1/tickers`, `GET /api/v1/orderbook/:symbol`, `GET /api/v1/ohlcv/:symbol`, `GET /api/v1/trades/:symbol`, `GET /api/v1/market-halt/:symbol`, `GET /api/v1/market-lifecycle/:symbol`, `GET /api/v1/charts/owner-values`, `GET /api/v1/orders/:id`, `GET /api/v1/orders/open`, `GET /api/v1/orders/closed`, `GET /api/v1/orders/cancel-all-after`, `GET /api/v1/funding-rate/:symbol`, `GET /api/v1/futures/order-types`, `GET /api/v1/positions`, `GET /api/v1/positions/closed`, `GET /api/v1/positions/:id`, `GET /api/v1/positions/:id/margin-call`, `GET /api/v1/futures/adl-disclosure`, `GET /api/v1/futures/adl-events`, `GET /api/v1/account/balance`, `GET /api/v1/account/fees`, `GET /api/v1/account/trades`, `GET /api/v1/ledger`, `GET /api/v1/statements/:id`, `GET /api/v1/statements/:id/file` |
| `trade:write`    | `POST /api/v1/orders`, `DELETE /api/v1/orders/:id`, `DELETE /api/v1/orders`, `POST /api/v1/orders/preview`, `POST /api/v1/orders/batch-amend`, `POST /api/v1/orders/batch-cancel`, `POST /api/v1/markets/:marketId/orders/mass-cancel`, `POST /api/v1/orders/cancel-all-after`, `POST /api/v1/positions`, `POST /api/v1/positions/:id/close`, `DELETE /api/v1/positions/:id`, `POST /api/v1/positions/margin`, `POST /api/v1/positions/margin/reduce`, `POST /api/v1/futures/adl-disclosure/ack`, `POST /api/v1/positions/leverage`, `POST /api/v1/positions/margin-mode`, `POST /api/v1/statements`                                                                                                                                                                                                                                                                                                                        |
| `trade:withdraw` | Never on a key: withdrawing is interactive only and no route takes it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
