# Base addresses

Each row is one protocol in one environment. A host appears here only when the owner has set it; a blank one reads host not set and nothing is guessed.

| Protocol  | Environment | Host         |
| --------- | ----------- | ------------ |
| REST      | Production  | host not set |
| REST      | Sandbox     | host not set |
| REST      | Regional    | host not set |
| WebSocket | Production  | host not set |
| WebSocket | Sandbox     | host not set |
| WebSocket | Regional    | host not set |
| FIX       | Production  | host not set |
| FIX       | Sandbox     | host not set |
| FIX       | Regional    | host not set |

The regional host rule is stated here once the owner sets it.
