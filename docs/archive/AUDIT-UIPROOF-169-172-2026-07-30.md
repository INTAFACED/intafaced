## 3 · Gaps vs plan

### Critical / gate-breaking for “B green”

1. **No live PROOF.md in this worktree; mainline status is honest unverified**  
   Sandbox Chromium SEGV is documented. Code cannot substitute for a desktop Terminal run of `pnpm ui:proof`.

2. **B4 canary never proven**  
   Mechanism exists; acceptance requires a red run then revert. Without that artefact, the gate is unfalsified.

3. **`report.mjs` false-PASS / stale-PROOF paths** (`report.mjs` L77–86, L140)
   - If Playwright JSON is missing but PNG shots exist → cell **PASS** with detail `shot present (no playwright json)`.
   - `ui:proof` uses `&&`, so a failed Playwright run never refreshes PROOF.md — **stale green PROOF.md can remain on disk** from a prior success while the latest command exited non-zero.
   - Agents (or Nitro) reading an old PROOF.md can believe a lie. Plan §1.2 / §4.2 demand a falsifiable current artefact.

### Important (fix before trusting the gate in CI or polish claims)

4. **B3 softened** — redirect-or-login-form instead of redirect-only. Document as intentional backends-down fixture **or** restore strict URL assert and accept red until auth fixture / guard behaviour is stable.

5. **B2 path mismatch** — plan’s `ls .artifacts/uiproof/*.png` vs implementation `shots/`. Update the operating plan acceptance line **or** also emit root-level copies. Prefer keeping `shots/` and fixing the plan/docs.

6. **Network allowlist is message-text-only** — does not use `consoleMessage.location().url` or Playwright `requestfailed`. High flake risk for B5; also over-broad `includes('fetch')` once a prefix substring appears.

7. **Reuse path skips `/app.js`** — letter-compliant with §2.4#1; can mark boot green against a server that serves HTML but not the bundle. Prefer: on reuse, require both statuses (small, high-value tighten).

8. **Pidfile/log not port-scoped** — A5 multi-port metadata collision.

9. **Runtime brand list ≠ full brand-scan** — missing rail-partner short codes, contact emails; weaker word boundaries on some assembled regexes (`engine-vendor` without `\b`). Split `ban()` correctly avoids **static self-hit** on `matrix.mjs` (good). brand-scan still scans `docs/*.md` and `tooling/uiproof/*.mjs` for literal names — split construction is the right pattern; keep it.

10. **Hardcoded sibling Node 18 path** in `boot.mjs` L85 — convenience only; fails closed via `resolveShellNode` error message if missing.
