## Money / auth doctrine (explicit)

- **Hold path:** only `ledger.post(recipes.orderHold(...))` on parent `userId` — no balances in trade tables as money truth (§0.6).
- **Rank discount:** affects **fee bps** on fill settlement via snapshotted `feeDiscountBps`, not a free balance credit. Identity down → **refuse order**, never invent 0 bps discount (would overcharge) and never invent max discount.
- **Sub-account:** label only; still gated (#246); orthogonal to #206 but same S2S posture.
- **CCXT private create/cancel:** always `TradeService` — no second hold path in REST.
- **Numeric types:** `Amount` = bigint; wire = decimal string; bps = int.
