## Layer detail

### #209 — Venue fabric (fill honesty)

- **Public market data:** `BinanceSpotMarketData` hits real REST/WS; levels validated; trade tape from venue events only.
- **Trading half deliberately incomplete:** With or without trade-only credentials, `placeOrder` / `cancel` / `fetch` / `openOrders` throw. Explicit anti-pattern documented: plausible `rejected` would let a router "try" venue, fill elsewhere, and call the whole route executed.
- **Account half:** `balances` / `positions` throw, never empty arrays ("flat").
- **Withdraw keys:** `assertTradeOnly` refuses at construction.
- **Sequenced book:** Withholds book on gap; does not serve desynced top-of-book as tradeable truth.
- **Cross-check:** Median consensus; `inconclusive` when &lt; `minVenues` (default 3); never invents a consensus price for routing; never renames another venue's mid as the diverged venue's.
- **Router (`planRoute`):** Effective price includes fees (ceil); internal preference only for ranking; legs report true effective price; unfilled amount honest.
- **Adjacent DEX plane:** Quote venues refuse `submit` — execution not laundered through quote fabric.

**Verdict #209:** Does **not** report fills it never made. Trade path is loud refusal, not soft success.

### #210 — Protocol CREATE2 / dev chain honesty

- **Account address:** `computeAccountAddress` is pure CREATE2 over EIP-1167 init code; owner bound into salt.
- **API gate:** `predictAddress` / `buildDeployment` call `requireAccountFactoryConfigured` (zero factory **or** zero implementation → refuse).
- **Deployed flag:** `deployed` from `eth_getCode` on predicted account address, not assumed true.
- **`chainStatus`:** `suiteConfigured` (env) ≠ `suiteDeployed` (code on chain); `usable` requires reachable **and** suiteDeployed. Health stays sync liveness (`ok: true` even without chain) — product must use `chainStatus`, not health, for "is chain real".
- **Typed refusals:** `protocol.chain_unreachable` / `contract_not_deployed` / `chain_id_mismatch` → 503 with code intact (not opaque 500).
- **No custody key** on this service.

**Verdict #210:** CREATE2 product surface does not succeed against 0x0 suite defaults. Live CREATE2 cross-check claimed by onchain tests (not re-executed this audit).

### #217 — Token factory honesty

- **Contracts:** `TokenFactory` CREATE2; salt = `keccak256(creator, userSalt)`; params in init code; collision reverts (`TokenAlreadyDeployed`) — not silent re-return of existing token (supply already minted).
- **Template:** Fixed supply, no mint/owner/upgrade — surface asserts `mintAuthorityRetained: false`.
- **API:** `predictTokenAddress` / `buildTokenDeployment` refuse zero factory first; supply decimal string → scaled bigint; zero recipient refused; deceptive unicode refused.
- **`tokenInfo`:** Code presence required; creator `null` if not from factory (not `0x0` as fake provenance); `matchesTemplate` masks immutables.
- **`launch.status`:** `audited: false` forced; `usable` = reachable ∧ factory deployed.
- **Tracker:** `launch.token-factory` status **`ready`**, not `done` (no audit, no mainnet chain decision) — aligns with code honesty.

**Residual P2:** `requireTokenFactoryConfigured` message says "not deployed" but only checks non-zero address. A wrong non-zero factory still yields publishable CREATE2 addresses from predict/build. Mitigated if UI gates on `launchUsable` / `launch.status.usable`.

**Verdict #217:** No 0x0 success invent on defaults; no platform-originated launch; no audit claim. Residual only under misconfigured non-zero factory without deploy proof on the predict path.

### #218 — Indexer projection honesty

- **Boot:** Missing `indexer.blocks` fails start; empty `INDEXER_RPC_URL` → `NullChainSource` + probe reason `indexer.chain_not_configured`; no default localhost RPC.
- **Venue 0x0:** Constructor refuse — empty logs forever would look like permanent no-liquidity.
- **Ingest:** Re-read own head hash every pass; reorg → `unwindTo` delete versions; reorg deeper than history → **halt** + `/ready` 503.
- **EVM adapter:** PublicClient only; logs by block hash; chain id verified; venue code re-checked; transport failure throws, recorded on `lastError`.
- **Reads:** Book/fills/positions from store only; money as strings; empty projection is empty + null provenance, not synthetic zeros.
- **Status:** `behindBy` null when tip unknown (never zero-by-default); `halted` / `lastError` / `chain` probe co-published.
- **Auth:** All data procedures permissionless; sovereignty boot assert; no key, no ledger URL under `src/`.
- **Open honesty:** `socket.clob-contracts` still open — DevVenue is a fixture; production CLOB events not claimed.

**Verdict #218:** Does not invent balances or chain state. Serves projections of what it ingested (or honest empty/null), and refuses configurations that would look like a permanent empty market.
