## Verdict

**PASS for both primaries.**  
placeOrder with a foreign/missing/revoked/unavailable sub-account **fails closed before any hold or order row**. Identity S2S requires service credentials; ownership is bound to the **edge principal `userId`**, not a client-supplied owner field. Private positions stream requires a verified access JWT (`trade:read` or `trade:write`), mounts on `/private/stream` separate from public `/stream`, fans only by hub `userId` match, and emits **ready + silence** until a real `positionUpdated` bus event exists — no invented positions. Money fields on these paths are **decimal strings** (`amountSchema`); holds go through **ledger recipes only**.

No P0. No P1. Residual notes are P2/info only.

## Money / balance doctrine (explicit)

- **#246:** Sub-account id is a **label** on `trade.orders.sub_account_id`. Hold asset/amount still keyed to **parent `userId`** via `orderHold`. No second balance table in identity or trade for sub-books on this path.
- **#227:** Private hub is a **mirror** of events (`hub.ts:7-8`). Position money fields are event strings only; no `ledger-client` in svc-ws.
- **Numeric types:** `feeBps: number` on fills is basis points, not a currency amount. All amount-bearing fields on `positionUpdated` / order / fill events use `amountSchema` (decimal string).
