## Three bars of “proper”

### Bar A — Audit completeness (know)

Every surface that can move value or mint trust from **his wave + anything merged after the last peace tip** is **named and judged** with evidence. Fail closed if unsure.

Includes: money recipes, auth, mounts, edge, vendor residue, tracker honesty, open release branches before merge.

### Bar B — Fix completeness (act)

Every finding that is:

- **P0 or P1 money/auth**, or
- **P2 that is pure code and doctrine-aligned** (shell must not mint; claim-before-post; no free userId reads),

…is **fixed on main with tests**, or blocked with a written reason that is **not** effort.

### Bar C — Peace scoreboard (feel)

You open **one file** (`PEACE-OF-MIND-AUDIT-CURRENT.md`) and it shows:

1. Tip SHA = real `origin/main`
2. Scoreboard lines honest
3. Residual only items that **legitimately require** you / Denon / counsel / live rails
4. Verdict: **keep building** / **not go-live** with plain reasons

When Bar C is true, “cleaned up after his dirty work” is true **for code and known doors**.  
Go-live is a **later** bar (rails, chain, kill drill, counsel list, licences).
