Pro desk color palettes — expanded

Locked for now: P21 Deep neutral · teal (provisional). Modular — change later by swapping tokens in intafaced.css. Doc: docs/COLOR-LOCK-P21-PROVISIONAL-2026-07-31.md

Scope of this page: color only (surfaces + text + accent + market green/red). Not layout, not density language, not dual-tone structure — those can graft later.

Hard rules (all options obey these): green/red = market only · accent never encodes PnL · no pure #000 bases (halation / fatigue) · no purple-glass SaaS · no casino neon on data · contrast high enough for long sessions · up/down locked for reading speed · placeholders are not balances.
Your direction (as I heard it): darker, closer to OKX’s color feel (charcoal / graphite panels, not pure black), but not so dark eyes tire. Board now includes a full deeper family (P21–P36) with different undertones (neutral / cool blue-black / green-graphite / warm-black / near-black + lifted panels) so options are not “the same gray with a different button.”

Reference — real desks (color jobs only)

OKX — charcoal panels, restrained chrome (your “darker but usable” anchor)

Hyperliquid — cool dark + teal accent discipline

Coinbase Advanced — calmer dark / blue-gray seriousness

dYdX — deep dark, purple accents (we do not clone that purple)

How to answer (color-only)

Reply with a palette id (or two if graft). Examples:

  • P01 — recommended if you want OKX-range dark + teal (start here)
  • P14 — same teal family, lifted panels (less eye fatigue)
  • P03 · P05 · P08 · P11 · P17 · P18 · P19 · P20
  • Graft: P14 base + P17 amber button

If you want darker (your latest note): start in Family 0 — P27 (OKX-darker teal) · P21 (deep neutral teal) · P33 (near-black + strong panel lift).

If eyes tire on deep dark: P14 or P01 (mid charcoal, more lifted).

Open: http://127.0.0.1:8765/VIEW-COLOR-PALETTES.html — scroll to Family 0 first for dark variants.

Still banned: purple neon, pure #000 void with no panel lift, rainbow accents, glass pastel SaaS.
