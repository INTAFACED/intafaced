## 0 · Philosophy

Path-walled parallel builders + forensic **master** coordinator is correct **while residual exists**.  
**Objective: maximize impact ÷ compute** — not seats, row counts, or motion.  
Same philosophy every wave; **N is evidence-driven** (not superstition). Soft target **8–16**, hard max **20** only with real method/babysit work. Honest **2–6** when drained is success.  
**Busy efficiency = FAIL.** Residual + promise-falsify > greenfield titles. Tip is law. Files survive chats.  
**Brevity = chat display only** — never skip pipeline steps or thin pastes.  
**Needle-moving residual > seat count.** Structure-only audits are incomplete.  
**Prefer N thick seats over N+pad.** Anti-pad beats arbitrary ≥8 when inventory is honestly thinner (substance OS §7).

## 2 · NEW pipeline (mandatory — never skip)

```
0. Read STATE + this runbook + substance OS (+ skeleton when writing pastes)
1. git fetch · tip SHA · last ~40 merge titles
2. gh pr list open · path tops · flag Denon / Shehzad / money · HOT HOLD paths
3. Stop notes: docs/LANE-STOP-* · closeouts · which walls banked on origin/main
4. Tracker parse on origin/main: ready/wip/Ø/shehzad/socket + ghost owners
5. Residual harvest trust order:
     banked stop-note parked → unbanked stop (still residual) → PR residuals
     → README promises → ADR/SPEC Done bars → tracker ready (weakest)
6. **Leverage-tag every unit L1–L7** (substance OS §3) · drop L7 · sparse L6
7. Falsify drained: landable needle-moving unit still open?
8. Wall map: exclusive path → units; packages/ rules (§3.1)
9. Subtract: sealed · open PR dual-write · Shehzad implement · live mid-flight walls
     · Denon invent-risk product-complete (unless residual micro only)
     (unless force — §2.1)
10. Score seats THICK/OK/THIN/THIN-NITRO/COLLIDE (substance OS §4)
11. Choose N from thick inventory only (§3) + theater cut (§3.2) + **ROI gate** (substance OS §5)
12. Write pastes from skeleton + quality bar (§5) · Engine A **ranked by leverage**
13. Self-audit: form · depth §5.1 · substance ROI · non-empty Done bars (anti-pad > fake quota)
14. Thicken or cut THIN / THIN-NITRO / COLLIDE before Nitro sees pastes
15. Write docs/paste-w<wave>/ + master PASTE-BUILD-WAVE-<wave>-<date>.md
16. Update STATE (tip, N, grades, nitro_only_open, clipboard_index=L01, risks)
17. Deliver §6 + clipboard first lane (full file pbcopy)
```

Coordinator never implements product residual.

### 2.1 · Force new (while some chats still cook)

1. List walls with **no** banked stop note and recent PR activity → **LIVE** (fence as babysit-only in new map or leave unassigned).
2. Walls with banked SAFE TO CLOSE or abandoned (§2.3) → free for reassignment.
3. Do **not** issue a second product paste on a LIVE wall.
4. Tell Nitro plainly which seats were left alone.

### 2.2 · Topup (partial wave)

1. Same harvest as NEW but only walls that are free/abandoned.
2. Mint k pastes (often 1–8); append to current wave folder as `T01…` or next free L ids.
3. Update STATE lane table; do not renumber live lanes.
4. Clipboard first topup paste.

### 2.3 · Abandoned lane

Treat as abandoned if: no open PR on wall, no commits on wave branches for that wall in the wave window, and no banked stop note — **or** Nitro says abandon.  
On next `new`/`topup`: residual returns to harvest; STATE marks prior id abandoned.

## 3 · Choosing N

| Signal                                   | Action                                                                                  |
| ---------------------------------------- | --------------------------------------------------------------------------------------- |
| Wall ≥3 real units                       | Product lane                                                                            |
| Product N low; tooling/vendor/board work | Method lanes                                                                            |
| Only Class X / §8 / Shehzad              | Fewer lanes or babysit/method — **say so**                                              |
| He wants max seats + residual exists     | Up to **20** **only if THICK/OK seats remain** after L1–L7 tag — never inflate with pad |
| Quant/execution greenfield no Done bar   | Refuse implement; docs-only optional                                                    |
| Shared package contention                | Merge lanes or assign package cluster to one lane                                       |

**No floor of 4** when drained. **No ceiling of 16** when residual supports more (max 20).

### 3.1 · Shared packages protocol

- `packages/contracts`, `packages/events`: **one writer lane per wave** for a given path cluster; cross-service units start with “contracts/events PR first”.
- `packages/auth`, `packages/ledger-client`: money-sensitive — prefer single writer; others depend via released tip only.
- Paste Engine A must name package paths when touched.

### 3.2 · Second pass — “is N theater?” / busy efficiency

Before deliver, cut any lane that is only:

- tracker thrash without user-visible/money/tooling safety outcome, or
- pure re-audit of fully sealed surface with no new break, or
- greenfield without Done bar, or
- **THIN / THIN-NITRO** after thicken attempt, or
- **COLLIDE** with Denon open / invent-risk product-complete, or
- L6/L7-dominated inventory (substance OS §3)

State the cut in delivery one-liner if N dropped. **Fewer thick > many thin** is a win, not a failure.

### 3.3 · features.mjs

- Default: **mountain-event only** by the lane that owns the mountain.
- Bulk honesty / multi-row clear: **BOARD+TOOLING** lane if present; else serialize one lane.
- Never encourage 16 concurrent tracker rewrites.

### 5.1 · Depth + substance gate (mandatory on every `new` / `audit pastes`)

Full rubric: [`COORDINATOR-SUBSTANCE-LEVERAGE-OS.md`](COORDINATOR-SUBSTANCE-LEVERAGE-OS.md) §4–§5.

Per lane score: **THICK** · **OK** · **THIN** · **THIN-NITRO** · **COLLIDE**.

| Grade      | Meaning                                                                   | Action                          |
| ---------- | ------------------------------------------------------------------------- | ------------------------------- |
| THICK      | multi-hour open inventory (PRs + parks + falsify) · high leverage density | keep                            |
| OK         | enough craft if Engine B brutal                                           | keep; thicken Done bars         |
| THIN       | risk early empty after babysit · low leverage                             | thicken **or** cut seat         |
| THIN-NITRO | only Class X / §8 parks                                                   | cut seat or method/babysit only |
| COLLIDE    | dual-write Denon/sibling live files                                       | fence or omit                   |

Structure audit alone is **not** enough — form can pass while residual is **busy efficiency**.  
**Anti-pad:** do not invent Engine A rows to hit 8; cut seat or honest short A + deep B.

## 6 · Delivery UX

1. **N · tip · substance grades · parallel OK / risks** (one line)
2. Table: id · plain what · leverage class (L1–L5) · backend/UI/tooling
3. ≤3 collision risks (packages, Denon HOT HOLD, open PRs)
4. ROI note: what needle this wave is for (not “16 seats filled”)
5. Clipboard + `next` / `all clipboard` / `topup` later
6. Paths: master + paste dir + substance OS
7. If N &lt; max: one honest why (thick-only win)

## 7 · Clipboard

| Mode                | Behavior                                                                                                           |
| ------------------- | ------------------------------------------------------------------------------------------------------------------ |
| After `new`/`topup` | First new id on clipboard; STATE index set                                                                         |
| `next`              | Advance; full-file `pbcopy`                                                                                        |
| `all clipboard`     | Full files in order · `cat "$f" \| pbcopy` · verify `pbpaste` bytes == file · **sleep ~1s** between · index = last |

**Only method:** simple shell pbcopy of paste markdown. Do **not** open browsers, TextEdit, or “clipboard boards” unless Nitro asks.
