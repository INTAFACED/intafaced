## 3 · The blocker nobody had found

**The depth/tape port cannot proceed yet, and it is not a shell problem.**

1. **The `/ws` proxy has never routed.** nginx sends `/ws` → `svc-ws:4014` with no URI part, so the path passes through unchanged. svc-ws serves `/stream` and `/private/stream` — there is no `/ws` route, and it 404s. Worse, `location /` catches `/stream` before it could reach a proxy. **There is no URL on `:8090` that reaches the depth stream.**
2. **svc-ws and svc-edge market-ID namespaces have zero overlap.** Edge exposes 16 markets, svc-ws knows 10, intersection **0**. A direct `101 Switching Protocols` against svc-ws closes immediately with `unknown market "a7cc445e-…"`. svc-ws derives its list from **svc-matching**.

So dropping a websocket client into the shell would not have worked, and fixing nginx alone would not have worked either. **svc-matching and svc-ws are the platform-integrity lane's services.** This needs that lane, or an explicit handoff, before any depth work is worth starting.

## 8 · Ways of working that were re-learned the hard way

- **Do not commit interrupted work as `wip: NOT reviewed, NOT verified`.** Seven branches carried that message under the wrong git identity and it took four rounds of agents to unpick. Commit at an honest boundary with a message stating what is and is not done, or leave it uncommitted in the worktree.
- **Commit identity is `D3-HAKI <intafaced@gmail.com>`.** The global `~/.gitconfig` was `theplugXE`; repo-local config is now correct, but check `git log --format='%an'` before pushing.
- **Never `git stash`.** It is shared across every worktree here and an agent already popped someone else's.
- **Path-intersect before merging**, not after: `gh pr diff <n> --name-only` against the other lane's PRs, then `git merge-tree --write-tree` for a real conflict answer. Two PRs touching the same file often do not conflict.
- **A green scan is not evidence until you know what it looks at.** `brand-scan` skips `vendor/`; the i18n gates will soon walk nothing; a gate that passes on an empty walk is worse than no gate.
