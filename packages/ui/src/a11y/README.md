# Access for the Lit glass look

WCAG 2.2 AA at the worst pixel, for every screen on the look. Owner: the access lane. Import the
logic from `@intafaced/ui/a11y` and the rules from `@intafaced/ui/a11y/a11y.css` (after `lit.css`).
Every CSS rule is scoped to `data-look="lit"`, so the app with the look off is unchanged.

| What                           | Where                            | Rule                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------------ | -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Worst-pixel contrast           | `contrast.ts`                    | 4.5:1 text, 3:1 large text and controls, no rounding. axe doesn't sample behind blur, so the look gate hides the text, screenshots the backdrop and calls `worstPixelContrast`. Money figures sit on solid or 80%+ tinted panels.                                                                                                                                                                              |
| Solid surfaces                 | `surfaces.ts`, `use-surfaces.ts` | `data-surfaces="solid"` on the root, kept by `useSolidSurfacesRoot()` mounted once; settings rows use `useSolidSurfaces()` and share its state. Solid when the person turns it on, or when the system asks for more contrast, forced colours or less transparency. Safari never tells the web about Reduce Transparency, so the switch is in the app. Nobody can turn it off against their own system setting. |
| Focus not obscured (SC 2.4.11) | `focus.ts`, CSS                  | Fixed bars carry `data-obscures="top"` or `"bottom"`. `trackObscuringBars()` measures them (the risk band grows with text size) and the CSS turns that into scroll padding, so a focused control scrolls clear.                                                                                                                                                                                                |
| Focus ring (SC 2.4.7)          | CSS                              | `--lit-focus` outline with a page-coloured halo, so it holds on any glass. Components may draw more, never less.                                                                                                                                                                                                                                                                                               |
| Targets (SC 2.5.8)             | CSS                              | Controls are at least 24 by 24 px. Links inside running text are exempt.                                                                                                                                                                                                                                                                                                                                       |
| Forced colours                 | CSS                              | Surfaces and controls get system-colour borders; selected states a Highlight outline; 3D canvases hide.                                                                                                                                                                                                                                                                                                        |
| Right to left                  | CSS                              | `data-ltr` keeps addresses, hashes, IBANs and book figures left-to-right and isolated; `data-dir-auto` isolates user text; `data-flip-rtl` mirrors icons that point along the reading direction. Logical properties only.                                                                                                                                                                                      |
| Text equivalents               | CSS                              | 3D objects are `aria-hidden`; what they show is said in text with `data-sr-only` (the holdings behind the sphere as a list).                                                                                                                                                                                                                                                                                   |

`a11y.test.ts` checks the WCAG reference ratios, the worst pixel on a synthetic glow, the switch
against live media changes and broken storage, the bar arithmetic, and that every CSS rule is
scoped to the look and uses logical properties only.
