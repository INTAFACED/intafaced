# @intafaced/sdk-ts

Private merchant payments client, not published; a blank base URL or API key refuses. Read `README.md` before editing.

- Tests: `*.test.*` files under `src/`. Run `pnpm --filter @intafaced/sdk-ts test`.
- Root rules that matter most here: The "Services" rules in the root AGENTS.md apply to anything that crosses a service.
- Env, ports and required settings: `docs/SERVICES.md` (generated). All other rules: root `AGENTS.md`.
